# Puffin

Puffin gives Codex its own agent identity: an email address, Slack, Discord and Telegram chats, texts, contacts, memories, a calendar and tasks. Codex can read and search the agent's messages, draft and reply, look up contacts, check free times and book meetings. Every message, reply and calendar invite it sends waits for your approval in Puffin, or as Approve / Reject buttons in your linked chat.

**Install:** `codex plugin marketplace add justpuffin/codex-plugin`, then add the Puffin plugin. The first time Codex uses a Puffin tool, it opens Puffin in your browser: sign in, pick the agent and click Allow. No API key is copied.

**From your phone:** ask Codex to "set up Codex from my phone" (the `puffin-phone` skill), or see the repository README.
